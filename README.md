One original fortune-cookie line for a software developer: "The code you wrote at 2 a.m. will introduce itself to you again at 9 a.m." `main.py` writes that single line to `entry.txt` in the output directory, deterministically, ready for make.fun's judge — a tired senior engineer picking the line that makes it smile and nod.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
